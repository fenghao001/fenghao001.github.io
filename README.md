# AI 多媒体作品集 · 站点包

一个可直接本地查看、可远程部署、方便改代码的静态作品集站点。

## 📁 目录结构

```
portfolio/
├── index.html              # 主页面（结构 + 内容）
├── assets/
│   └── css/
│       └── style.css       # 全部样式（已从原 HTML 拆分出来，方便修改）
├── media/                  # 所有视频 / 图片素材（约 740MB）
│   ├── 01-商业广告/
│   ├── 02-机甲大战/
│   ├── 03-电商视觉/
│   ├── 04-变身换装/
│   ├── 05-国风儿童/
│   ├── 06-泛娱乐/
│   └── 07-仙侠高燃/
├── _archive/               # 旧版本 / 预览图 / 脚本备份（不参与部署）
├── README.md
└── .gitignore
```

> 封面图已内联进 `index.html`（base64），所以即使只复制 `index.html` 也能看到封面。
> 其余媒体通过相对路径 `media/...` 引用，因此整个 `portfolio/` 文件夹要保持在一起。

## 🖥️ 本地查看

两种方式任选其一：

**方式 A：直接打开（最简单）**
双击 `index.html`，用浏览器打开即可。视频、图片都能正常播放。
（注意：个别浏览器对 `file://` 下的本地视频有严格限制，若视频无法播放，用方式 B。）

**方式 B：本地服务器（推荐，体验最稳）**
在 `portfolio/` 目录下执行：

```bash
# Python 自带，无需安装
python -m http.server 8080
```

然后浏览器访问 <http://localhost:8080> 即可。

## ☁️ 远程查看（让别人也能看）

整个站点是无构建的纯静态文件，可部署到任意静态托管：

- **CloudStudio 一键部署**：在 WorkBuddy 里让我执行「部署到 CloudStudio」，会生成一个公开链接，别人直接打开就能看（注意：`media/` 约 740MB，上传需要一些时间/流量）。
- **GitHub Pages / Vercel / Netlify / 对象存储 + CDN**：把 `portfolio/` 目录（建议排除 `_archive/`）上传即可，免费且稳定。
- **临时内网穿透**：本地起 `http.server` 后配合内网穿透工具，可临时分享给其他人。

> 部署时只需上传 `index.html`、`assets/`、`media/` 三个部分；`_archive/` 是备份，不必上传。链接：https://2163c35988764237b2b4b22ed485be81.gz1.agentos-app.net/

## ✏️ 后期修改代码

代码已经拆分为「结构」和「样式」两层，改起来很直观：

| 想改什么 | 改哪个文件 |
| --- | --- |
| 文字、项目板块、联系方式 | `index.html` |
| 颜色、字体、布局、卡片样式 | `assets/css/style.css` |
| 增删视频 / 图片 | 放进 `media/` 对应分类，再在 `index.html` 里加一行 `<video src="media/...">` 或 `<img src="media/...">` |

改完保存，刷新浏览器即可看到效果，无需任何编译。

## 📝 备注

- 媒体素材较大（约 740MB），建议用固态硬盘存放，并配合版本管理（如 `git init`，`.gitignore` 已忽略 `_archive/` 与媒体二进制，可按需调整）。
- 联系信息（姓名 / 电话 / 邮箱 / 微信）在 `index.html` 末尾「联系我」板块，可直接编辑。
